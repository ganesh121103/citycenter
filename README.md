📦 citycenter – Online Shopping Website

citycenter is a simple frontend online shopping web application built using HTML, CSS, and JavaScript.
This project demonstrates a clean UI layout for displaying products and is a good foundation for expanding into a complete e-commerce website.

🚀 Features

Clean and modern homepage layout
Product listing interface
Responsive design elements
Simple JavaScript-based interactions
Easy to customize and extend

📁 Folder Structure
citycenter/
│
├── index.html      # Main web page
├── styles.css      # All styling for the website
├── script.js       # JavaScript for interactions
│
└── .vscode/        # Optional: VS Code settings folder

🛠️ How to Run the Project

This project is static (no backend required).
1. Clone the repository
git clone https://github.com/ganesh121103/citycenter.git
2. Go to the project folder
cd citycenter
3. Open the website
Simply open index.html in any browser:
Double-click index.html

— or —

Right-click → "Open with Browser"
That’s it! The website will run locally.
